# RAGAS 실측 비교 분석

작성 시각: 2026-11-26T11:04:33+09:00

## 평가 범위

저장된 최초 Mac 실험과 조건 추출·필터·정규화 보완 결과를 같은 RAGAS 심사 설정으로 재평가했다. 기존 Test 중 과거 참고 근거가 있는 T01~T17을 각 A/B/C에서 평가했다. 새 검색·답변 생성이나 새 최종 Test 실행은 아니다. 근거 없는 3문항은 이 평균에서 제외했다.

최초 구성은 Kiwi BM25·직접 RRF·LLM reranker, 개선 구성은 교안 BM25·EnsembleRetriever·Cross-Encoder와 조건 추출·필터·정규화다. 따라서 최초 대비 변화 전체를 필터 하나의 효과로 해석하지 않는다.

차이는 0~1 척도의 점수 차이다. Context Precision은 관련 문맥의 상위 배치, Context Recall은 참고 정답 진술을 검색 문맥이 뒷받침하는 정도를 평가한다. 두 지표는 정답 확률이나 현재 매물 확인 정확도가 아니다.

- **B**: Precision 상승(+0.8446), Recall 상승(+0.6639). 검색 문맥 판정의 변화이며 생성 답변의 의미 정확도는 별도로 확인해야 한다.

## 조건 일치 검색 지표와 F1

다음 지표는 같은 원본 CSV에서 모든 조건을 동시에 만족하는 거래를 정답 집합으로 삼아 결정적으로 계산한 값이다. 위 RAGAS Recall과 분모가 다르므로 직접 섞지 않는다. F1은 질문별 문서 Precision과 집합 Recall의 조화평균을 낸 뒤 17문항 평균한 값이다.

| 구성 | 초기 문서 Precision | 개선 문서 Precision | 초기 집합 Recall@5 | 개선 집합 Recall@5 | 초기 집합 F1@5 | 개선 집합 F1@5 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| A | 0.2353 | 1.0000 | 0.0832 | 0.2481 | 0.0948 | 0.3370 |
| B | 0.1412 | 1.0000 | 0.0576 | 0.2481 | 0.0627 | 0.3370 |
| C | 0.3059 | 1.0000 | 0.0926 | 0.2481 | 0.1113 | 0.3370 |

관련 거래가 수백 건이어도 최대 5개만 반환하므로 집합 Recall과 F1은 낮을 수 있다. 반면 RAGAS Recall은 전체 거래 회수율이 아니라 참고 진술의 문맥 지원 여부를 본다.

## 캐싱 효과의 구분

이번 RAGAS 비교는 초기와 정규화 보완 결과에 대한 심사다. 캐시 적중은 같은 답변·출처를 재사용하므로 추가 검색 품질 상승으로 계산하지 않는다. 캐시 miss/hit/버전 변경은 저장 결과를 주입한 검증을 통과했지만 실제 모델 포함 지연·토큰·비용 절감 측정과는 구분한다.

## 한계와 원본 기록

- 기존 질문을 분석해 개선한 회귀 평가이며 새 질문에서의 일반 성능을 보장하지 않는다.
- LLM 심사이므로 실행마다 점수가 달라질 수 있다. 과거 보고서 수치와 이번 재채점 값도 다를 수 있다.
- 이번 RAGAS 실행은 Context Precision·Recall만 측정했다. Faithfulness·Answer Relevancy를 새로 측정한 것은 아니다.
- 묶음별 원본 점수·질문 ID·입력 해시는 체크포인트에 보존하고, 동일한 완료 묶음은 재사용한다.
- 조건 추출·필터·정규화·캐싱의 구현 위치와 처리 규칙은 [구현 상세](./caching_and_quality_comparison.md)를 참고한다.
- 이전 열 이름 오류와 수정은 [실행 오류 분석](./ragas_execution_analysis.md)에 기록했다.

## 실측 결과에 대한 추가 해석

- **개선의 핵심:** 질문의 숫자·지역·유형 조건을 검색 전에 강제하고, 건물명·표현 차이 때문에
  올바른 후보가 탈락하던 문제를 정규화로 줄인 뒤 관련 문맥의 비율과 참고 정답 지원도가 함께 상승했다.
  다만 최초 대비 전체 변화에는 BM25·reranker 구성 변경도 포함돼 각 개선 요소의 개별 기여율을 분리할 수 없다.
- **A에서 남은 차이:** T16의 개선 후 RAGAS Recall이 0.6667이라 A 평균이 0.9804다.
  해당 문항은 규칙 기반 조건 검사에서는 반환 거래가 모두 맞는 것으로 계산됐다.
  이 차이는 RAGAS의 참고 진술 판정과 거래 조건 일치 판정이 서로 다름을 보여준다.
  원본 점수만으로 특정 생성 오류나 데이터 누락을 확정하지 않는다.
- **B/C가 모두 1.0인 의미:** 이미 분석한 17문항과 이번 심사 설정에서 검색 문맥이 높은 평가를 받았다는 뜻이다.
  일반 질문·근거 없는 질문·답변 의미 정확도까지 모두 검증됐다는 뜻은 아니다.
- **캐시의 기여:** 검색 품질 상승은 조건 처리와 검색 구성 개선의 결과이고, 캐시는 그 결과를 재사용한다.
  실제 응답 시간·비용 절감 수치는 이번 평가에서 측정하지 않았다.

이번 값은 과거 보고서의 RAGAS 값에 개선 후 값만 이어 붙인 표가 아니라,
초기·개선 후 저장 문맥을 이번 실행에서 같은 설정으로 다시 심사한 비교다.
기존 보고서의 Recall(예: 최초 C 0.787)과 이번 초기 C 0.4559를 혼용하지 않는다.
