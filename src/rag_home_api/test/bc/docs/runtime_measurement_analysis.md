## 채점 오류와 복구

검색·생성 20건은 모두 저장됐지만 채점에서 다음 오류가 발생했다.

```text
KeyError: 'course_v0_small:SR_6553e7bb35f6_structural_v0_000'
```

DB 저장소 ID에는 컬렉션 접두사가 있고 원본 청크 ID에는 없어서 생긴 채점기의 ID 대조 오류다.
알려진 `course_v0_small:` 접두사만 제거한 뒤 실제 원본 청크 존재를 검증하도록 수정했다.
저장한 검색 ID·답변·문맥은 바꾸지 않고, 원본 ID와 정규화 ID를 구분했다.
이번 복구에서 검색·추출·생성 API는 다시 호출하지 않았다.
측정 당시 실행기 해시는 고정 파일에 보존하고, 수정한 채점기 해시는 별도로 기록했다.

## 기존 평가와의 관계

이미 분석한 T01~T17에서는 C Hit@5가 17/17이었지만, 새 T21~T37은 15/17이다.
기존 17문항의 높은 Context Precision이 새로운 표현까지 모두 처리한다는 뜻은 아니라는 것을 보여준다.
이번 새 질문 실행은 RAGAS 심사를 하지 않았으므로 새 Context Precision·Recall 값으로 제시하지 않는다.
캐시 실환경 측정과 T16 반복 심사는 이번 `--stage holdout` 실행에 포함되지 않았다.
