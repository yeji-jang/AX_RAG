# 평가셋 — 법령 파트(최지훈) + 공공임대 후보

- 파일: `법령파트_평가셋.json`(팀에 넘길 것, 19문항), `후보풀_공공임대.json`(다른 파트 참고, 11문항)
- 형식: 팀장(최기혁) dev.json 형식 + `eval_category`·`allowed_row_ids`·`evidence_quotes`
- 정답(`key_facts`)·근거는 공유 JSONL 원문에서 직접 확인. 근거 발췌는 원문과 자동 대조(불일치 0)
- `allowed_row_ids` = 근거 쪽·조문 줄 id. `allowed_chunk_ids`는 메인 청킹 확정 뒤 줄 id로 채움
- 같은 규칙을 그대로 설명하는 가이드·법령 사본 쪽도 허용 근거에 포함(공고문 속 공공임대 규칙은 제외)
- 만든 방법·수정 이력·사용자 질문 판정: `../실험기록.md` 5절

## 팀이 정할 것

- 파트별로 dev·test에서 맡을 문항 수
- `allowed_chunk_ids` 채우는 방식(메인 청킹 확정 뒤 줄 id에서 변환)
- 범위 밖 질문(서울 밖·대출·세금)의 정답 상태: `insufficient_evidence` / 별도 "범위 밖"
- 정답 충족 채점 기준(`key_facts` 전부 / 부분 점수)
