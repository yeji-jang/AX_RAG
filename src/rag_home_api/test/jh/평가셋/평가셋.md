## 원문·청크·적용 조건

- 답변 가능 8개는 LAW_ 원문 조문만 허용 근거로 사용함. 가이드·상담사례·공고를 정답 근거에 넣지 않음.
- 각 문항의 evidence_quotes에 조문 발췌, source_location에 조항·항, source_url에 공개 출처, application_conditions에 적용 범위를 기록함.
- allowed_chunk_ids는 현재 jh_500(500/100)과 jh_1000(1000/200) 각각의 정확한 청크로 매핑함. 두 설정의 16개 매핑을 로컬에서 확인함.
- 질문이 요구하는 사실만 key_facts에 둠. 신고 기관·신고 방식·재증액 금지 기간·다른 비용 분류·계약 해지 등 질문에서 묻지 않은 사실을 필수로 추가하지 않음.
- 근거 부족 문항은 법령상 수치를 묻되 수집 원문으로 확정할 수 없는 경우임. 수치가 현실의 모든 법령에 존재하지 않는다는 주장으로 해석하지 않음.
- DEV-09는 법정 배상 단가표의 부재, DEV-10은 수집 시행령의 별표 본문 누락을 로컬에서 확인함. 근거 ID·청크·key_facts는 비워 둠.

## 로컬 검증과 이전 실행 구분

