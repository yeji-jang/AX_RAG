# MVP 수집 범위와 검증

기준일: 2026-11-23. 자료 탐색·검색·크롤링의 규모를 줄여 최소 자료로 서울 주거 질문을 검증하는 구성입니다.

> 2026-11-23 갱신: 전월세 계약 자료(rent_contracts)는 `shared/docs/kh/서울_전월세_최근1년`(최근 1년, 필요한 칸만 남긴 CSV 527,145건)으로 대체했습니다.

## 이번에 공유하는 자료

- 전월세 원본: 서울 전체 연간 ZIP **1종**. 이미 확보한 파일을 재사용했습니다.
- 서울 **25개 자치구**의 2025년 계약 **580,277건**. 원본 CSV 1,084,942행에서 계약연도 밖 62,186행과 지역 미확인/서울 밖 5행을 제외했고, 원본에 두 번씩 들어 있던 완전 중복 439,318행을 1건만 남겼고, yj·bc CSV와 같은 거래 3,156건은 그쪽에 두고 여기서 뺐습니다(2026-11-23).
- 공공임대 대표 공고 **3건**, 핵심 공고문·주택목록 **5개**. 이 중 SH·LH 주택목록의 공급 기록 **1,269개**, 조건별 가격 **5,076개**를 정제했습니다.
- 기존 거리 예시 **14개 단지 × 3개 목적지 = 42건**. 이 부분은 3개 구의 예시이며 서울 전체 주택의 거리 자료가 아닙니다.

계약 행 수가 많아도 수집원은 파일 1종입니다. 파일 전체를 지역별로 다시 크롤링하지 않았습니다. 검색용 지역별 JS는 이 원본에서 생성한 로컬 가공 파일입니다.

## 제외한 것

공공임대 전수 공고, 추가 사진·도면·서식 대량 수집, 민간 앱 실시간 매물, 가전 옵션 추정, 정책대출·세금·청약제도 설명, 실제 통근시간 API 호출은 MVP에서 제외했습니다.

이전의 초기 3개 구 정제 자료와 이후 추가 다운로드는 원래 프로젝트에 보존하지만 MVP 공유 ZIP과 현재 HTML의 기본 데이터에는 넣지 않았습니다. 추가 다운로드에는 서버의 일일 한도 오류 응답도 있어 미검증 보조자료로 취급합니다. 새 네트워크 수집은 중단했습니다.

## 검증과 한계

원본과 정제 데이터의 행 수, 서울 25개 구 포함 여부, 선택한 공고·첨부 수, 공유 파일 존재 여부는 `reports/mvp_validation.json`에 기록합니다. ZIP의 포함 파일과 경로는 `data/mvp/package_manifest.json`에서 확인할 수 있습니다.

서울시 파일은 접수년도별 자료이므로 모든 2025년 계약이 완전히 포착되었다고 보장하지 않습니다. 파일명의 연도와 계약일을 구분했습니다. 공공임대 3건은 대표 표본이며 서울 전체 공고가 아닙니다. 가전·관리비·현재 공실·실제 통근시간은 미확인 상태입니다.
