# 서울 주거자료 MVP 공유 안내

## 팀원에게 줄 파일

`서울주거_RAG_MVP_공유.zip` 한 개를 전달하면 됩니다. 압축을 모두 푼 다음 폴더 안의 `index.html`을 Chrome 또는 Edge에서 여세요. HTML과 `ui`, `data`, `docs` 폴더를 함께 두어야 검색과 원본 링크가 동작합니다. 별도 설치·로그인·서버 실행은 필요 없습니다.

## MVP에 포함한 자료

- 서울 전체: 서울시 전월세 연간 파일 1종에서 2025년 계약을 선정했습니다. 자치구별 반복 크롤링을 하지 않고 이미 확보한 서울 전체 파일을 재사용했습니다.
- 공공임대: SH 청년 매입임대, LH 청년 매입임대, 청년안심주택 공공임대의 대표 공고 3건입니다. 공고문·주택목록 PDF/XLSX 5개만 포함합니다.
- 거리: 기존에 계산한 14개 단지와 서울시청·여의도역·강남역 사이의 직선거리 예시입니다. 서울 전체 주택의 거리나 통근시간 데이터가 아닙니다.

원본은 `data/raw/`, RAG·분석에 사용할 최소 CSV는 `data/mvp/`에 있습니다. `data/mvp/files.json`에서 공유 대상 원본의 URL·해시를 확인할 수 있습니다.

## 무엇을 확인할 수 있나요

지역, 주택유형, 면적, 보증금, 월세, 계약일, 원문 건축년도로 과거 계약을 탐색할 수 있습니다. 공공임대는 원문에 명시된 방구조·방수와 자격별 가격 조건을 함께 봅니다.

가전 옵션·관리비·현재 공실·실제 대중교통시간이 원문에서 확인되지 않으면 미확인으로 남겼습니다. 실거래와 공고 공급정보를 현재 입주 가능한 매물로 안내하지 않습니다.

## 범위

사회초년생의 서울 전월세·공공임대 탐색을 검증하기 위한 MVP입니다. 정책대출·청약제도 상담·세금·서울 밖 주택은 답변 범위에서 제외합니다. 공공임대 대표 3건이 서울 전체 공고를 뜻하지 않습니다.

## 파일을 이동하거나 수정할 때

폴더 내부 경로를 유지하세요. 데이터가 갱신되면 빌더로 HTML과 지역별 검색 파일을 다시 생성해야 합니다. 이 자료에는 임베딩·답변 모델·벡터 DB가 포함되어 있지 않습니다.
