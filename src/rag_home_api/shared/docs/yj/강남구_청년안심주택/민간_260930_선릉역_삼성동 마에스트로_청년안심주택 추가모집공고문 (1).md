## <u>청년안심주택</u> 민간임대 입주(예정)자 안내문 

청년안심주택은 서울시와청년안심주택사업자(시행사,임대사업자) 간“청년안심주택건립및운영에관한협약” 을체결하여공급되며, 공공임대주택과민간임대주택이혼합되어있는주택입니다.

청년안심주택민간임대는민간임대주택에관한법령및규정을따르는민간임대주택으로서, 민간임대입주(예정) 자분들의임대보증금관련사고예방등을위해다음과같은임차인필수확인사항을반드시검토하시기바랍니다.
