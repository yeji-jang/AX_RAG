# 문제 정의: 서울 상경 청년을 위한 전월세·공공임대 탐색 RAG

> 서울에 처음 상경한 20~30대 청년은 **"내 예산·조건으로 들어갈 수 있는 전월세 집과 공공임대"**를 찾기 위해
> 여러 사이트의 매물, 수십 쪽짜리 공고문, 실거래가를 직접 읽고 비교해야 한다.
> 정보는 공개돼 있지만 **흩어져 있고, 읽기 어렵고, 내 상황에 맞게 해석해 주는 곳이 없다.**
> 이 프로젝트는 공고문·법령·실거래 데이터를 근거로, 출처와 함께 답하는 RAG 서비스를 만든다.

- 작성 기준일: 2026-11-23
- 데이터 기준: `shared/docs/데이터목록.csv` v0

---

## 1. 사용자

**서울로 상경해 거주할 전·월세 집을 찾는 20~30대 청년**

| 항목 | 내용 |
|---|---|
| 대상 | 만 19~39세, 취업·진학으로 서울에 처음 독립하는 1인 가구 (청년안심주택·청년 매입임대 자격 연령과 겹침) |
| 경제 상황 | 사회초년생 소득, 모아 둔 보증금이 적음 (수백만~수천만원) |
| 주거 경험 | 직접 집을 구해 본 경험이 거의 없음. 전월세 용어·계약 절차·공공임대 제도를 잘 모름 |
| 주요 고민 | 예산 안에서 출퇴근 가능한 곳, 이 가격이 적정한지, 공공임대 자격이 되는지, 전세사기는 아닌지 |

**대표 사용자 예시**: 만 26세, 지방에서 상경한 IT 회사 신입. 모은 돈 2,000만원, 월세 60만원 이하 원룸 또는 청년안심주택을 찾고 있다.

> 참고 (데이터 기준): 서울 전월세 거래 중 **33㎡ 이하(원룸급)가 42.3%**이고, 33㎡ 이하 월세 계약의 중앙값은 **보증금 1,000만원 / 월세 50만원**, 전세 중앙값은 **1억 9,400만원**이다. 사회초년생의 예산으로는 전세보다 월세나 공공임대가 현실적인 선택지인 경우가 많다.

## 2. 기존 탐색 과정

| 구분 | 방법 | 문제점 |
|---|---|---|
| 온라인 | 네이버 부동산, 직방, 호갱노노 등 | 보이는 가격이 집주인이 부른 **호가**라서 적정 가격인지 판단하기 어렵다. 공공임대 정보는 거의 없다 |
| 온라인 | LH청약플러스, SH, 청년안심주택 사이트 | 기관마다 사이트가 따로 있고 공고 시기도 제각각이다. 공고문이 PDF 수십 쪽이고 자격·소득 기준이 표로 되어 있어 **내가 해당되는지 판단하기 어렵다** |
| 온라인 | 국토부 실거래가 공개시스템 | 조회 조건 설정, 다운로드, 엑셀 정리를 직접 해야 한다 |
| 오프라인 | 부동산 중개소 | 중개사가 가진 매물 위주로 안내받는다. 공공임대는 다루지 않는다 |
| 오프라인 | 임장 (현장 방문) | 지방에서 상경하는 경우 여러 번 방문하기 어렵고 시간과 비용이 든다 |

**핵심 문제**: 민간 매물, 공공임대 공고, 실거래가, 계약 법령이 **각각 다른 곳에** 흩어져 있어서 한 번에 비교할 수 없다.

## 4. 오답·근거 부족의 영향

답변이 **실제 돈과 주거에 대한 결정**으로 이어지기 때문에, 오답의 피해가 크다.

| 오답 유형 | 사용자 피해 |
|---|---|
| 자격을 "된다"고 잘못 안내 | 서류 준비에 시간 낭비, 부적격 판정. 당첨 후 취소되면 재신청 제한 같은 불이익 |
| 자격을 "안 된다"고 잘못 안내 | 저렴한 공공임대 기회를 놓침 |
| 일정·마감일 오류 | 신청 기간을 놓침. 다음 공고까지 몇 달이 걸릴 수 있음 |
| 시세 오류 | 적정가보다 비싸게 계약하거나, 시세보다 높은 전세로 **전세사기 위험**이 커짐 |
| 금액 단위 오류 | 실거래 CSV는 **만원**, 공공임대 가격은 **원** 단위라 섞이면 금액이 1만 배 틀어짐 |
| 오래된 정보 안내 | 마감된 공고나 바뀐 법령을 현재 정보처럼 안내 |

**대응 원칙**

1. 모든 답변에 **출처**를 표시한다 (공고명, 쪽 번호, 데이터 기준일).
2. 근거 문서를 찾지 못하면 **"확인할 수 없음"이라고 답하고** 공식 문의처를 안내한다. 추측해서 답하지 않는다.
3. 평균·중앙값·건수 같은 숫자는 **LLM이 계산하지 않고 SQL로 계산**한다.
4. 금액은 전처리 단계에서 **원 단위 정수로 통일**하고, 보여줄 때만 "1억 2,000만원" 형식으로 바꾼다.
5. 자격 판단은 "공고문 기준으로 충족할 가능성이 높음" 수준으로 안내하고, **최종 확인은 공고 원문에서** 하도록 권한다.

## 5. RAG 선택 이유

| 대안 | 한계 | RAG의 장점 |
|---|---|---|
| LLM 단독 (ChatGPT 등) | 최신 공고를 모르고, 금액·일정을 그럴듯하게 지어냄 | 실제 공고문과 실거래 데이터를 근거로 답하고 출처를 보여줄 수 있음 |
| 파인튜닝 | 공고가 매달 새로 나오는데, 그때마다 다시 학습해야 하고 비용이 큼 | 문서만 교체하면 바로 최신 정보로 답함 |
| 키워드 검색·필터 사이트 | "1순위 청년 자격이 뭐야?"처럼 조건을 해석해 주지 못하고, 여러 문서를 종합하지 못함 | 자연어 질문을 이해하고 여러 문서를 종합해서 답함 |

**데이터 성격에 맞춘 하이브리드 구조**

- **글 문서** (공고문 4,599쪽, 법령·가이드 430줄): 청킹한 뒤 PGVector에 저장하고, 벡터 검색과 BM25를 함께 쓴다. 공고문은 자격·소득 기준이 표로 되어 있어 키워드 검색이 꼭 필요하다.
- **숫자 데이터** (전월세 562,624건, 공공임대 가격 5,076건): 임베딩하지 않고 PostgreSQL 테이블에 넣어 SQL로 조회·집계한다.
- **라우터**: 질문 유형에 따라 문서 검색과 SQL 중 어디로 보낼지(또는 둘 다) 정한다.

## 6. 제외 범위

| 제외 항목 | 이유 |
|---|---|
| 매매, 분양 청약 | 대상 사용자의 관심사가 아니고, 데이터와 판단 기준이 완전히 다름 |
| 서울 외 지역 | v0 데이터가 서울만 포함 |
| 실시간 매물 추천·중개 | 매물이 실제로 남아 있는지 보장할 수 없고, 중개 행위는 법적 이슈가 있음. 실거래 데이터는 **이미 체결된 계약**임 |
| 법률 자문, 계약서 검토, 전세사기 확정 판단 | 전문가 영역이고 잘못 답하면 피해가 큼. 법령·가이드 내용 안내와 공식 상담 기관 연결까지만 함 |
| 대출 상품 추천 | 금융 상품 추천 규제와 개인 신용 정보 문제. 추후 확장 후보 |
| 신청 대행, 개인정보 수집 | 서비스 범위 밖이고 보안 부담이 큼 |
| 데이터 기준일 이후의 정보 | 수집 시점(2026-11-23)까지만 답하고, 답변에 기준일을 표시 |

**v0 데이터의 한계 (답변 시 명시)**

- 공공임대 호실·가격 데이터(`public_housing_units`, `public_rent_scenarios`)는 **청년 매입임대 공고 2건**뿐이다. 다른 공고의 호실별 가격은 공고문 텍스트에서만 찾을 수 있다.
- SH 주택관리현황은 **2023-05-03 기준**이라 이후 생긴 단지는 없다.
- 전월세 면적 기준이 섞여 있다 (서울시 데이터는 임대면적, 국토부 데이터는 전용면적, 단독다가구는 계약면적).
- 단독다가구는 지번·건물명·층이 공개되지 않는다.

## 7. 품질·시간·비용 우선순위

**품질 > 시간 > 비용**

| 순위 | 항목 | 이유 | 이렇게 반영한다 |
|---|---|---|---|
| 1 | **품질** (정확성·근거) | 오답이 곧 금전 손해와 기회 손실로 이어진다 (4번 참고) | 출처 필수, 근거 없으면 답변 거절, 숫자는 SQL 계산, RAGAS로 정기 평가 |
| 2 | **시간** (응답 속도) | 대화형 서비스라 너무 느리면 이탈하지만, 정확도를 희생할 만큼 급하지는 않다 | 검색 결과 수(k)와 재정렬 단계를 조절해 목표 응답 시간 안에 맞춤 |
| 3 | **비용** | 팀 프로젝트 규모에서는 API 비용이 크지 않고, 임베딩은 한 번만 하면 된다 | 저렴한 임베딩 모델 사용, 숫자 데이터는 임베딩하지 않아 비용 절감 |

## 8. 팀의 목표값

> v0 단계에서는 **목표를 느슨하게** 잡고, 먼저 전체 흐름을 완성한 뒤 평가 결과를 보며 올려 간다.

### 평가셋

- 질문 유형(3번 표 6개 분류)별로 고르게 **질문 60개 이상**과 정답·근거 위치를 만든다.
- 그중 **데이터로 답할 수 없는 질문 10개 이상**을 포함한다 (거절 능력 평가용).

### 질문 영역별 목표 (RAGAS)

| 질문 영역 | 해당 질문 유형 (3번 표) | Faithfulness | Answer Relevancy | Context Recall |
|---|---|---|---|---|
| **전월세 비교** | 민간 시세, 공공 vs 민간 비교 | **0.6 이상** | **0.6 이상** | **0.6 이상** |
| **공공임대** | 공공임대 자격, 공고 상세, 공공임대 가격 | **0.7 이상** | **0.7 이상** | **0.7 이상** |

- 공공임대 질문은 자격·일정 오답의 피해가 커서(4번 참고) 전월세 비교보다 목표를 높게 잡는다.
- 계약 상식(법령·가이드) 질문은 v0에서는 공공임대 영역과 같은 기준(0.7)으로 평가한다.
